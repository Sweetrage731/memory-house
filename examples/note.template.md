# A title in plain words

**The user's exact words** (YYYY-MM-DD HH:MM):
> "Paste them here, unchanged. Leave this out only when the source is claude."

**What it means:** one or two sentences in my own words. If the source is claude, start with
"My own idea:" and say why.

**Ends:** (temporary things only) a date, or "when the user says so".

## Changes

Never rewrite what is above. Add a new dated line here instead, with the exact words if the user said
something. Updating status, check_by or ends in the frontmatter is fine, so the index stays honest.

- YYYY-MM-DD (user): "..."
