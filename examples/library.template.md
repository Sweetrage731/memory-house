# Library

Longer things live here: what happened, what was decided, how a project stood.

How to write here:
- Add, never erase. Every entry starts with a date and a source (user, claude or agreed).
- Quote the user's exact words for anything they asked for or decided.
- To correct an entry, add a new dated line under it that says what changed and who said so.
- Never paste passwords, keys or tokens.
