# Memory index

Each line says where it came from:
[user] the note quotes the user's exact words. [claude] my own idea or inference, not the user's rule.
[agreed] we decided it together.
Format: - [who] what it is (YYYY-MM-DD) -> notes/file-name.md
A temporary line says how it ends. When it ends, start the line with ENDED and keep it until the next tidy.
